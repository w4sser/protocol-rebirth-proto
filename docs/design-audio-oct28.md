# Audio design, October 28

The approved audio layer supports mobile landscape play without changing combat or economy. All runtime tuning lives in `data/audio.js`; the shared manager is `ui/audio.js` and raid event routing is `nodspel/audio.js`.

Ambience: 24-second seamless beds, each with a two-second wrap crossfade. Archipelago contains wind, sea wash, distant synthesized gulls and buoy bells. Bunker contains electrical hum, drips and ventilation. Base has a quiet low drone. An optional low music pulse is generated and registered but remains off by default (`audio.loop('music', 'pulse')`). Ambience follows the current area and stops at raid end/page exit.

SFX: concrete, gravel, metal and wood footsteps; carbine, SMG, shotgun and rifle fire/reload/empty; enemy and wall impacts; grunt, rusher, thrower, tank, turret and generator hit/death; kill confirmation; common through legendary pickups; bag full; medkit; dash; perk open/select; UI tap/back/confirm; alarm; hunter wave sting; final raid countdown; extract success; death/failure. Unknown enemies/weapons use the grunt/carbine family. Reload cues follow actual incremental reloads. Footsteps use wood on archipelago piers and house floors, gravel on islands, concrete in bunker/town, and explicit authored floor.surface overrides (including metal).

B.I.T. uses the eight existing F1 Kokoro am_fenrir recordings. Hunters inbound: wave spawned. Scrap detected: first rare-or-better pickup per raid. Heal budget low: low/empty budget threshold crossed. Extraction marked: final extraction revealed. Bag heavy: full bag notice. Nice shot: every fifth kill, with a long cooldown. Signal lost: terminal failure. Welcome back: integrated result ingested on base return. No speculative or random dialogue. Single VO reservation includes loading time; a global 12-second cooldown and per-line 60-second cooldown (90 seconds for nice shot, 15 seconds for death/return) prevent chatter. Events during another VO are dropped, never stacked.

Mix: master feeds music, ambience, SFX and voice buses. Voice ducks music, ambience and SFX by exactly -6 dB (linear gain 0.501187), restoring current user volumes afterward. Short gain ramps avoid clicks. SFX vary pitch/gain slightly. Settings expose master/music/SFX/voice and mute in the existing base settings popup; settings persist locally without changing game saves. Ambience has its own configurable bus and follows master. iOS/Safari audio starts after the first pointerdown/touchend; blocked/unsupported audio fails quietly. Assets load and decode lazily with shared promises; stopped or replaced loops cannot start from stale loads.

All audio is generated free/local: numpy plus ffmpeg for original CC0 procedural assets; existing local CPU F1 TTS for BIT. Every shipping file is listed in `assets/audio/LICENSES.md`. Both mono Vorbis OGG and low-bitrate AAC M4A ship, selecting OGG only when the browser reports Vorbis support. Older iOS uses AAC. Total shipping audio, including both formats, must remain below 2,000,000 bytes. No commercial services, downloaded samples, or noncommercial-only voice auditions ship.

Regenerate with `/workspace/tts-venv/bin/python tools/audio/gen-sfx.py`. Generate the 20-second audition with `python3 tools/audio/mix-demo.py`; the default output is `/workspace/rostprov/mix-demo.ogg`. The demo is outside the shipping asset budget.
