# Bunker home theme

The owner supplied these recordings for v2.19.0 and confirmed that Robert owns the rights. They are played locally through Web Audio after the first user gesture. No audio generation or paid service is involved.

| File | Rights |
| --- | --- |
| `music/bunker-theme.m4a` | All rights reserved, Robert |
| `music/bunker-theme.ogg` | All rights reserved, Robert |

The generated SFX, voice and pulse asset budget in `assets/audio/LICENSES.md` remains unchanged. The supplied full-length theme is additional music and is loaded on demand; it is excluded from that generated-asset budget. The asset check still verifies both theme formats and these rights entries.

`DATA.audio.startTheme` defaults to `null`. Set it to `'bunker-theme'` to opt into music on the start screen. The lobby uses the theme independently.
